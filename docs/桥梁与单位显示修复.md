# 桥梁对齐、坦克朝向与模型显示修复

本轮在 `D:\Program\红色警戒2` 使用纯 C17 修复显示层，继续只读加载原版 1.006。中国阵营仍只保留接口。本轮没有安装外部引擎，也没有把 C++、C# 或 Rust 引入产品。

## 修复内容

1. 高桥按原始状态帧 0–8 上移 16 像素，9–17 上移 31 像素；低桥不使用高桥偏移。完整、损坏、断口与修复共用该锚点，桥面鼠标命中仍根据真实桥层高度生成。
2. 车身在平地、桥面和坡地统一应用原有底盘矩阵，再转换模型与地图的 Y 轴。相机固定为 45 度方位、30 度俯角，不再通过旋转相机代替平地车身转向。
3. 炮塔、炮管使用相对车身方向；模型旋转角与模拟方向的增量符号相反。已读入的 `TurretOffset` 现在也参与显示，偏移跟随车身，炮塔围绕偏移后的轴心转动。
4. 战场使用固定像素比例与模型地面原点，不再随朝向、炮塔和坡面重新适配模型包围盒。血条根据可见模型上边界定位。资源查看器仍可自动缩放，保持原有浏览方式。
5. 三剧场分别读取 `unittem.pal`、`unitsno.pal`、`uniturb.pal`；切图时清除单位图像缓存，避免沿用上一剧场的颜色。

`src/battle_scene.c` 负责战场锚点、方向和部件设置，`src/voxel_render.c` 提供固定比例绘制，`src/battle_viewer.c` 使用明确的模型原点放置图像。VXL/HVA 解码和通用坐标变换保持原有语义，避免根据未经核对的格式推测改变资源解析。

## 开源参考与原版核对

- [OpenRA RA2 桥梁序列](https://github.com/OpenRA/ra2/blob/61e24e3c1d7b586aa55a86096d29e1559aa9b994/mods/ra2/sequences/bridges.yaml)：两个方向的桥梁偏移及帧组。
- [VERA20k 桥梁显示](https://github.com/YuriPlanet/vera20k/blob/28615d91bdbf0f9581ef06470bc92f156fe4d375/src/app/presentation/instances/bridges.rs)：桥梁状态与绘制偏移的逆向线索。
- [Phobos 部件矩阵](https://github.com/Phobos-developers/Phobos/blob/effa1ef14eafeb516ac747b3c0448df813873cb7/src/Ext/TechnoType/Hooks.MatrixOp.cpp)：车身、炮塔偏移、相对朝向与炮管合成次序。
- [OpenRA VXL/HVA 变换](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/Graphics/Voxel.cs)：核对 HVA 平移、节比例和坐标轴约定；文件指纹见本轮参考清单。
- [redalert2-recomp 体素绘制分析](https://github.com/sp00nznet/redalert2-recomp/blob/a8d2d5fb9d0c1bb369d0d9688b7f7664981435df/docs/voxels.md)：固定投影、图像偏移与缓存的关系。

这些项目用于核对坐标约定和绘制过程。产品实现为本项目的 C 代码，未引入它们的运行时或原版机器码。尤里的地址没有直接套用到 1.006。

`scripts/reference-rendering.py` 先验证本地原版 `game.exe` 的 SHA-256，再隔离执行 1.006 的 `475457..47549e` 桥梁偏移分支，核对 72 组状态与材质。相机数学片段显式提供 45/60 度角常量，执行原版矩阵合成与底盘函数，再与 C 绘制的 32 向标记像素比较；允许一个像素内的栅格误差。这些是显式夹具中的原版指令对照，不是原版整局渲染器的逐像素验收。

## 查看与复验

直接运行 `D:\Program\红色警戒2\build\ra2battle.exe`：

- 普通交互战场参数：`--map MP06T2.map`。
- 桥梁演示参数：`--bridge-demo`。
- 默认只读资源目录：`H:\开发\运行版本\原版1.006`。

无需 CMD 启动脚本。回退程序和本轮修改前的完整源码位于 `build/rendering-preserved`。

`ra2rendertests` 的无参数模式检查固定比例、32 向车身、独立炮塔方向、画布尺寸与模型原点；传入原版目录和输出目录后，还会生成两种原版坦克的方向图与 21 坡面矩阵图，并在原始地图通行格中检查八个方向的实际位移和车身方向。方向图上每组三行分别为车身与炮塔同向、炮塔固定、车身固定；数字为模拟方向角，不是屏幕方位角。坡面图使用真实模型与合成坡号夹具，真实坡格另由原生窗口测试覆盖。

完整复验脚本为 `scripts/verify-rendering.ps1 -AddressSanitizer`。它检查普通版与内存检查版、旧桥梁回放、新任务回放、三剧场窗口、桥口与真实坡面窗口、原版地图语料、CMake/CTest、原始输入指纹和旧项目清单。并行中国设计 Markdown 的变化继续单独记录。

## 验收边界

模拟版本继续为 7，回放标识继续为 `RA2RPL9`。十三份模拟核心源文件与修改前逐个比较，代码未改；显示不会进入固定步状态或回放摘要。

本轮修复对齐、方向、比例与锚点问题，不将软件立方体表面绘制宣称为原版体素栅格器的逐像素复刻。原版光照、投影阴影、栏杆与单位间的逐像素遮挡、残骸和坠桥动画仍有独立待验项。完整原版实机场景的逐帧对照仍待取得记录，不能用回放摘要一致替代视觉验收。
