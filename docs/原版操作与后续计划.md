# 原版 1.006 操作与后续计划

当前任务行为与版本 3 验证见[战场任务与路径规划](战场任务与路径规划.md)。以下保留输入调整阶段的结果；其版本 2 校验与旧回放兼容结论只适用于该历史阶段。

本轮调整现有最小战场的输入，继续使用 C17、中文注释与既定排版。实际键位来自原版 `ra2.mix|local.mix|keyboard.ini` 的 `[Hotkey]`，共 89 项；运行时只读解析，不修改原版配置。项目保留明确的功能边界，不能把键位保留称为对应玩法已经完成。

## 已接入的操作

| 操作 | 行为 |
|---|---|
| 左键己方单位 / 左键拖框 | 选择 / 框选己方；单独点击敌方可检视，但不能操控 |
| 选中己方后左键地面 / 敌方 | 下达移动 / 攻击命令 |
| 右键单击 | 取消选择；已执行的移动命令继续，停止需用 S |
| 右键按住拖动 / 鼠标靠近战场边缘 | 滚动视角；到达图像边界停止，移出窗口或失去焦点停止滚屏 |
| Shift+左键 | 增加或移除己方选择；Shift+拖框加选 |
| 双击己方 / T | 当前屏幕同类型选择；快速连按 T 选择全图同类型 |
| Ctrl+1..9、0 | 建立编队；0 为第 10 队 |
| 数字 / Shift+数字 / Alt+数字 | 选择编队 / 加选编队 / 选择并居中；快速双按数字也居中 |
| N / P | 轮选下一个己方单位 / 选择全图己方作战单位 |
| F / 数字小键盘 5（Clear） | 跟随选择 / 将当前选择居中 |
| S | 下达停止命令，当前停靠行为沿用第七阶段模拟 |
| 空格 | 跳到最新战场命中警报；快速连续按可轮转最近 8 个记录，不暂停游戏 |
| Ctrl+F1..F4 / F1..F4 | 设置 / 跳转视角书签 |
| Esc | 打开选项并暂停；关闭后恢复进入选项前的运行状态 |
| Ctrl+C | 保存窗口 BMP 截图到程序目录的 `screenshots` 子目录 |

保存/读取命令回放、暂停、单步、通行层与回到测试单位使用显式工具按钮。F5..F12 按原版保留给多人嘲讽等用途，不触发回放文件对话框或模拟单步。A 保留结盟含义。Home、End、方向键按原版配置属于侧栏相关键，当前不会滚动战场或代替基地定位。

战场默认按 100% 原始像素显示。滚轮不缩放战场，中键不再拖图；需要放大查看时，在 Esc 选项中显式选择 75%、100%、150% 或 200% 的预览比例。该控件是开发查看功能。

本机 1.006 的原始配置明确规定 `NextObject=78`（N）、`ScreenCapture=579`（Ctrl+C）。某些手册版本对轮选等键的文字有差异，因此以实际资源为默认键位依据，不自行补上 M/Y 等未绑定操作。Ctrl、Shift、Alt 修饰位分别按包内配置的 0x200、0x100、0x400 解释。

鼠标选择、命令与滚屏语义参考原版官方手册的界面及游戏基础章节：[原版手册扫描文本](https://manualmachine.com/gamespc/commandconquerredalert2/1117998-user-manual/)。默认键位文本的本轮只读副本位于 `reports/input-20261019/original-keyboard.ini`。

## 尚未完成的原版操作

后续任务阶段已实现 Ctrl+左键强制开火、Ctrl+Shift+左键移动攻击、G 警戒、X 散开、Z 路径点与闭合巡逻，并接入固定步和版本 3 回放。Alt+左键强制移动/碾压、Ctrl+Alt 指定护卫与完整节点编辑仍待实现，修饰点击不退化成其他命令。

H 基地定位、D 部署、Q/W/E/R 生产侧栏、K 修理、L 变卖、结盟/外交、聊天、信标及多人嘲讽等，随对应的建筑、生产和多人系统实现。当前键位保持原始用途。原版细分滚屏速度、鼠标图形和所有边界交互仍需更完整的实机对照，不宣称整套界面已经逐像素复刻。

本轮只改变查看器和输入层，没有改变整数模拟核心、原版数值或回放版本。选择、编队、相机、书签、选项和截图不进入游戏状态摘要；真正的移动/攻击/停止仍走下一固定步的有序命令队列。第七阶段既有回放应得到相同最终摘要。

## 接下来的开发顺序

1. **补齐原版战场行为与操作。** 优先完成强制开火、移动攻击、警戒、散开和路径点；在独立的原版对照副本中校准完整转弯、连续停靠、坡向、炮弹轨迹与伤害边界。新命令继续纳入回放与逐步状态检查。
2. **建立最小遭遇战闭环。** 实际建筑图像与选择、建设厂、建造摆放、生产队列、矿车采矿/卸矿、资金、电力、科技和胜负。相应接入原版生产侧栏与快捷键，形成可持续游玩的单人流程。
3. **开始多核与显示性能工作。** 先记录加载、模拟步、寻路和显示耗时，再优化数据布局及单位容量。资源解码、寻路、索敌和可见性读取固定快照并行计算，按固定阶段和稳定顺序提交。使用相同地图与命令比较 1/2/4/8 个工作线程的逐步摘要、步耗时与卡顿，不以 CPU 占用率作为通过标准；不必等全战役完成才开始多核工作。
4. **扩展原版完整内容。** 步兵、海空、桥梁、特殊武器、经验/老兵、完整 AI、音效语音和现代绘制；随后推进版本化存档、战役与联机同步。每类内容单独记录规则支持与实际运行结果。
5. **媒体升级与中国内容包。** 接入成熟 C 音视频接口和流式播放，对比 AV1/HEVC 在高画质下的体积、软硬件解码负担与设备覆盖，再选择发行方案。中国阵营设计定稿后，通过已预留的数据接口接入，不阻塞原版主线。

第 1 项的上述任务行为已实现；下一次仍先完成连续停靠、完整转弯、坡向和弹道边界的原版校准，再进入第 2 项。第 2 项稳定后即穿插第 3 项的测量与并行任务；存档和联机应保持与确定性模拟共同演进。
