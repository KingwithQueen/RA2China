## 已实现与运行方法

运行 `build/ra2battle.exe`，左键/拖框选择蓝方，右键地面移动、右键红方攻击，A 攻击最近敌人，S 停止，空格暂停，F10 单步，F5 保存、F9 回放。真实 MTNK/GTNK、HTNK 模型与原版爆炸帧已显示。

新增原版速度转换、独立车体/炮塔转向、地形与坡度速度、末端减速和中心停靠；新增敌我目标、射程寻路、装填、整数弧线弹体、护甲/范围伤害、受击还击、摧毁与占格释放。固定模拟步、命令回放、R250 显式状态和完整战斗摘要已接入。中国只保留禁用的扩展命名空间。

算法与范围说明见《移动校准与最小战斗》。新增核心为 `battle_motion.c`、`battle_rules.c`、`battle_combat.c`，新增验证为 `combat_test.c`、`motion_vectors.c`、`reference-motion.py`、`verify-combat.ps1`。

## 验证方法

- 原版指令对照：严格核验 game.exe SHA-256 后，隔离执行原版速度、缩放、转向、坡度、单次减速及随机范围抽取。对照 C 输出的全部数值，不执行旧游戏进程。
- C 测试：正常模拟、阻挡/绕路、射程、装填、护甲、移动目标落空、弹体碰撞、停靠、相互摧毁、占格释放、逐步回放、不同墙钟节奏、恶意回放语义、超大规则数值溢出。
- 实际新引擎窗口：在温带、雪地、城市三张原版地图，以 Windows 消息驱动真实选择、移动、攻击和回放；捕获窗口像素，并核看命中及摧毁截图。这不等同于人工实玩原版。
- 独立进程：三张地图各录制 900 步炮战，再从新进程重放并比较最终摘要；AddressSanitizer 构建再重放同一文件。
- 两种构建入口：build.ps1 与 CMake；正常测试、内存检查测试和原生窗口分别记录。

## 原始资料与并行编辑

本轮没有写入 `H:\开发` 或原始游戏资源。game.exe 与 5 个 MIX 包均保存前后 SHA-256。旧项目完整路径、长度和最后写入时间清单各保存一份，未覆盖最初记录。

清单检测到 `H:\开发\研究资料\中国阵营重设计` 最初有 8 份文档更新，用户已在本对话确认另一对话正在同步设计。验收结束时累计 11 份 Markdown 有变化，其中 9 份为原有文件更新、2 份为新增；均位于该明确设计目录，保留其更新，其他旧文件继续严格比较。`old_project_unchanged=false` 如实表示全目录有并行变化；`old_project_preserved` 单独表示原始输入和其他旧文件是否保持本轮保护边界。

差异记录在 `concurrent-design-changes.json`，不回退、不覆盖设计文档。最初严格验收因该清单变化未通过的结果另存为 `validation-first-pass-with-concurrent-changes.json`，保留发现过程。

## 仍未完成的验收

原版窄指令样本对照不等于完整游戏一致。尚未实场景验收原版连续曲线行走、精确坡向、停靠浮点累计边界、全部碰撞、炮弹轨迹和完整伤害边界。当前最小弹道、命中半径和范围衰减仍有近似，不能据此宣称玩法已经完全重现。

建筑仍为标记与阻挡，桥梁双层明确阻断；无完整 AI、经济、生产、采矿、海空/步兵、存档、联机或多核性能验收。已知 29,798 个原版缺失地形引用继续保留。媒体与 AV1/HEVC 不进入本阶段。
