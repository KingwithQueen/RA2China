# 编码规范

本次及后续新增代码遵循以下约定；维护旧代码时按修改范围逐步统一，不为格式调整无关模块。

- 产品库、工具和测试使用纯 C17，不引入 C++ 源文件或 C++ 运行库。
- 新增注释使用中文，重点说明所有权、处理顺序、格式例外和判断依据，避免逐行重复代码。
- 一条完整语句通常占一行，不为了排列参数频繁拆行。语句或字符串确实过长时，按参数或逻辑边界换行。
- 不把多个无关语句压在同一行；循环头和必要的测试宏按语言语法处理。
- 使用 4 个空格缩进、UTF-8 编码和 LF 换行，参考 `.editorconfig` 的 160 字符长行提示。
- 动态数组检查容量和乘法溢出，失败路径释放已经取得的资源。
- 所有输入文档保留来源和行号；未经建模的字段保留原文并报告，不默默丢弃。
- 数据解析、引用检查和游戏行为分别记录支持状态，不以字段存在或数值转换成功替代运行验收。
- 原版和旧 MOD 资料只读，构建、测试、日志及报告均写入新项目目录。
- 原生构建使用 `/std:c17 /TC /W4 /WX`，并执行有意义的边界测试、真实资料对照和内存访问检查。
- 新增 C 代码可使用项目的 `.clang-format` 统一格式；只格式化本次修改范围，不重排无关模块。
