## 保留的兼容信息

- `jeep.vxl` 与配套 HVA 的节数不同，`probe.hva` 是一帧零节占位；两者可解析，但不能建立完整动画配对。查看器读取此类场景会说明失败并保留原预览。
- `art2barl.vxl`、`htk.vxl`、`htktur.vxl`、`trnsport.vxl` 的单节名称不同。仅在双方均为单节时按顺序连接，窗口和 JSON 明确标注；多节不猜测对应关系。HTK 连同炮塔、炮管的实际预览也经过窗口检查。
- 原版 3,336 个体素使用已知方向表以外的法线编号。保留这些编号并逐节计数，预览用统一向上方向，不越界查询、不修改源数据。
- VPL 的保留字段是原始填充值，完整保留。其内嵌调色板作为原始八位 RGB 处理，外部 PAL 仍遵循上一阶段的六位规则。

详细来源与列表见正式报告目录中的 `资源配对与兼容信息.md`。这些原有差异没有混入解析失败计数，也没有被写回“修复”。
