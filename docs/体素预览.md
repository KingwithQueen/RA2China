# VXL、HVA、VPL 与体素预览

运行 `D:\Program\红色警戒2\build\ra2voxelviewer.exe`。产品为纯 C17，使用 Win32/GDI 显示软件绘制结果；不依赖 C++、.NET、Python、OpenGL 或 Direct3D。资源只读挂载，所有构建、验证与默认截图写入新项目。

## 查看资源

默认使用 `H:\开发\运行版本\原版1.006` 和 `H:\开发\运行版本\中国开局验证`。首次挂载会核对包校验，需要几秒钟。资源集加载后缓存在当前进程中。

|---|---|---|---|
| 犀牛/中国轻型坦克 | HTNK | CNLTNK | HTNK |
| 天启坦克 | mtnk.vxl | CNAPOC | MTNK |
| 航母 | CARRIER | CARRIER2 | CARRIER |

| 直升机动画 | SHAD | SEEK | SHAD |
| 多节步行动画参考 | hmec.vxl | hmec.vxl | hmec |

输入规则对象时读取该对象自己的 Image 和 UIName；直接输入 `.vxl` 文件名时按原始文件加载。例如原版对象 MTNK 的 Image 是 GTNK，而 `mtnk.vxl` 是天启模型。中国 CNAPOC 的 Image=MTNK 直接指向美术文件，不再把它当作另一个规则对象反复解析。

- 在模型下拉框选择对象或 VXL 文件，也可手动输入后点“读取”。已知名称目录包含 184 个 VXL；不是 MIX 未知哈希名称的还原器。
- 勾选“合成车体、炮塔与炮管”时，按实际存在的同基名 `tur`、`barl` 文件合成，缺失的可选文件不虚构。原始部件坐标保留。
- “左转/右转”“俯视/平视”调整视角；拖动画布也可旋转，滚轮缩放。“复位”恢复默认视角与缩放。
- “炮塔向左/右”独立旋转已加载的炮塔与炮管，不修改 HVA 帧或车体方向。
- 上一帧、下一帧、帧号跳转与“播放 HVA”控制真实动画。单帧资源禁用播放，界面显示静态姿态。SHAD/SEEK 有 2 帧，hmec 有 17 帧。
- 右上角可选择某个模型节。支持 VPL 查色表开关、四种阵营颜色、原始调色板显示及温带/雪地/城市 PAL。
- 右侧提供中文名称、规则对象、Image、每个 VXL/HVA 的实际来源与兼容提示。“保存预览图”保存当前窗口 BMP，不写回资源。

可以用 `--original <目录> --mod <目录>` 指定资源位置。预设需要原版 ra2.mix、LANGUAGE.MIX 及指定中国目录的 ecache91.mix。`--self-test <已存在输出目录>` 自动检查原生按钮、绘制、动画、换色及文件错误，短暂显示窗口但不抢占输入焦点。

## 公共接口与所有权

接口在 `include/ra2/voxel.h`，使用前清零拥有型对象，成功打开后先关闭再复用。失败不发布部分对象；错误信息仅在函数返回 false 时使用。

| 接口 | 内容 |
|---|---|
| ra_vxl_parse / ra_vxl_close | 拥有完整节元数据和解码体素，不借用原始文件 |
| ra_hva_parse / ra_hva_close | 拥有节名及帧优先、行主序 3×4 矩阵 |
| ra_hva_bind | 按 ASCII 大小写不敏感的节名连接，不按名字缺失自动猜测多节关系 |
| ra_vpl_parse / ra_vpl_lookup | 保留头部与原始内嵌调色板，查色表借用输入；输出为外部 PAL 索引 |
| ra_voxel_transform | 应用边界、体素尺寸、节比例与 HVA 仿射变换 |
| ra_voxel_normal | 检查类型和编号后查询 36/244 个方向数据，未知编号返回 false |
| ra_voxel_image_create / close | 拥有 BGR 颜色缓冲和深度缓冲 |
| ra_voxel_render | 根据部件、帧和相机参数绘制，不修改 VXL/HVA/VPL |

VXL/HVA 完成解析后可释放输入；VPL 输入必须保持有效。绘制器的模型和矩阵只读，不同任务可使用独立输出缓冲；本阶段没有引入线程池。场景辅助层拥有资源及对象，并在发布/移动场景后重连内部指针；内部辅助结构不属于稳定的公共 ABI。

## 格式检查

VXL 校验 802 字节头部、28 字节节头、92 字节尾部、体数据大小、柱起止表、含末字节的终点、跳空长度、连续体素长度、重复计数和 Z 高度。使用文件中三种柱偏移，不假设表必须紧邻。保留节编号、标志、内嵌调色板、边界、静态矩阵、比例、颜色和法线编号。限制最多 1024 节、总计 16 Mi 个解码体素，拒绝非有限数、非法尺寸和截断。

HVA 校验帧数、节数、矩阵数量、文件长度、节名重复和非有限浮点数，限制至 1,048,576 个矩阵。`probe.hva` 是一帧、零节的 24 字节占位，允许解析但不能与非空 VXL 建立动画关系。VPL 校验重映射范围、表数和总长度，保留未知字段；原版保留字段包含编码器填充值，不强制为零。内嵌 VPL 调色板是原始八位字节，不套用 PAL 的六位校验。

HVA 节名优先匹配。预览层只对 VXL/HVA 都只有一节的名称差异使用按序连接，并在窗口和 JSON 标记；多节缺失或数量不符直接报告，不静默套用其他部件动画。详见报告中的《资源配对与兼容信息》。

## 绘制约定与当前边界

绘制使用完整立方体表面、内部面剔除、正交投影和逐像素深度缓冲，保持画布纵横比。每个部件单独应用 HVA、部件转向和相机角度；以全部 HVA 帧的投影边界确定取景，避免播放时缩放跳动。帧号从 1 显示，库内从 0 开始；不同帧数的附加部件按各自帧数循环。

节空间点先按边界及体素尺寸转换，再应用 HVA。平移分量按各轴体素步长与节比例换算，最后乘节比例。零比例遗留文件在预览中按 1 处理；输入原值保留。公共函数提供可单独核对的坐标输出，验证报告含逐帧坐标探针。

光照使用 VXL 方向、HVA/部件旋转与固定方向光，计算明暗表编号后查询 VPL，再通过实际 PAL 取色。阵营色在重映射范围内预览。原版存在 3,336 个超出已知方向表的法线编号，保留编号并使用统一向上方向作预览，同时逐节报告数量，绝不作为数组下标直接读取。

当前是资源预览，不是原版渲染逐像素重现。光照、换色梯度、炮塔旋转轴和部件合成采用明确的预览约定；尚未解释 art.ini 的全部 TurretOffset、FLH、武器俯仰、光照与阴影机制。未实现地形遮挡、战场动画调度、战斗、AI、存档或多核模拟。视角旋转不计入 HVA 动画验收。

## 验证与格式参考

`scripts/verify-voxels.ps1 -AddressSanitizer` 构建纯 C 产品、运行 C 测试、解析两套 369 个文件、检查配对、绘制分类样本的全部 HVA 帧和多个方向、运行原生窗口检查，并保存输入前后指纹。独立 Python 参考脚本只用于第二份验收，不参与产品或正常构建。

格式事实核对 [XCC 的 VXL 读取](https://github.com/OlafvdSpek/xcc/blob/master/misc/vxl_file.cpp)、[OpenRA 的 VXL 读取](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/FileFormats/VxlReader.cs)、[HVA 读取](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/FileFormats/HvaReader.cs) 与 [模型变换](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/Graphics/Voxel.cs)。方向数值表经 [OpenRA 收录的 Westwood 方向数据](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/Traits/World/VoxelNormalsPalette.cs) 核对，仅保存 36/244 个数值向量；VPL 的头部、内嵌调色板和每个查色值同时与实际文件独立解码对照。C 解析器与软件绘制器独立编写，没有引入其 C++/C# 产品库。
