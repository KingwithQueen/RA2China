## 原版对照的证据与范围

`scripts/reference-motion.py` 先验证原版 `game.exe` 的 SHA-256 为 `fe67fdac5073530a79baec14c4e072b5e7e4c0c462cee9659870c5330e9e6e3e`，再在隔离内存中执行原版的窄指令路径。对象、类型、虚表和国家速度乘数使用显式夹具，国家乘数为 1；原始文件不改动，也不启动旧游戏。

该 Python 工具仅用于独立验收，产品实现没有固定地址、原版二进制依赖或 Python 运行依赖。验证环境只读使用旧项目已有的 pefile、Unicorn 包，并禁用 Python 字节码写入。

| 项目 | 原版结果与当前 C 实现 |
|---|---|
| Speed | 先限制 0..100，再计算 `floor(Speed×256/100)`，最大 255；MTNK 的 7 → 17，HTNK 的 6 → 15 lepton/逻辑步 |
| 坐标 | 一个格 256 lepton，内部一个 lepton 为 256 整数坐标单位；跨路段保留本步剩余移动量 |
| 地形与坡度 | 履带按目标地表 Track 系数；原版 TrackedUphill=1.0、TrackedDownhill=1.2。最终查询速度向零取整到整数 lepton |
| 浮点边界 | 原版 x87 中 `15×1.2` 略小于 18，截断得到 17；C 使用整数判断倍精度系数的舍入方向，保留这个边界，不使用宿主浮点状态 |
| ROT | 16 位方向，最短有符号角差，半圈选择负向；速率 ROT×256，时长为角差绝对值除以速率的整数部分 |
| 转向插值 | 原版先做 `角差/时长` 的整数除法，再乘剩余步；不可交换顺序。车体与炮塔各自保存转向状态 |
| 停靠 | 原版默认 SlowdownDistance=500 lepton、DeaccelerationFactor=0.002；低于该距离每步减少基础速度×0.002，最低约 0.3；抵达目标中心时精确停止 |
| ROF 随机延迟 | 原版已完成炮击的装填间隔有 0..2 步随机增量；当前为 ROF 加该增量，显式 R250 状态进入回放与摘要 |

速度 12 组、缩放速度 12 组、转向 16 组、坡度 6 组、减速 12 组，共 58 组运动计算；另比较 512 次原版随机范围抽取，覆盖环形索引回绕和拒绝重抽。`ra2motioncheck.exe` 输出 C 结果，参考工具逐项比较完整转向序列及全部抽取值。

随机抽取的原版路径使用相同的显式 250 项初始状态。当前初始状态由新引擎固定种子生成，属于回放版本约定；没有复刻原版整局随机数初始化、国家/老兵修正或全局随机消费顺序。

减速百分比使用万分比定点数。所列减速样本对照初始百分比为 1 的单次更新，尚未穷举原版浮点连续累计的全部取整边界；后续完整停靠轨迹对照仍需补充这些情况。

**证据只覆盖所列指令与输入。** 当前路格间采用先转车体再沿直线行驶，尚未复刻原版 Locomotor 的完整转弯弧线、加速器、细分碰撞和全部坡向。相邻高度差、坡格门槛、斜角和双格占用检查沿用通行层；坡向和整条实地图路线仍需原游戏场景计时/轨迹对照。固定 15 步/秒是本项目参考模拟频率，未实现原版游戏速度档位与墙钟映射。

当前炮弹在发射时保存目标坐标，之后不会追踪移动目标；按整数飞行时间推进并绘制弧线，沿每步轨迹细分检查高地、悬崖和墙。命中按护甲比例、距离衰减和整数截断扣血；正值伤害最低为 1。范围内友军也可能受伤，受击敌人可还击。摧毁计数、击杀归属、冷却、弹体及爆炸存续状态全部参与校验。

## 固定步、回放与校验

每步顺序固定为：按序执行命令 → 目标/攻击寻路与瞄准 → 按单位编号移动 → 按弹体槽号推进已有炮弹并结算 → 按单位编号尝试开火。抽取随机值只发生在成功创建弹体时。显示、选择、相机和消息泵不拥有模拟状态。

`RA2RPL7`，格式与模拟版本为 2。文件包括地图/规则/美术内容指纹、完整初始状态摘要、单位队伍、移动/攻击/停止命令、结束步、最终状态摘要和全文件 SHA-1。新增命令记录为五个小端 32 位数：执行步、序号、单位、目标、种类；目标为格号或单位号，最近敌人用 0。

状态摘要明确逐字段序列化，包括地表、真实占格表、规则类型与武器、路径、车体/炮塔转向、生命、目标、装填、击杀、全部有效弹体及 250 项随机状态。当前未执行命令、显示数据、指针、填充和寻路临时缓冲不进入状态摘要；全回放摘要另行覆盖完整命令。SHA-1 用于复现检查，不提供签名认证。

加载先完整验证格式、长度、摘要、版本、内容、初始队伍和命令语义，成功后再替换现场。失败保留当前战场。第六阶段 `RA2RPL6` 文件会被明确拒绝；保留在 `build/stage6-preserved` 的旧程序可供历史恢复，旧报告不覆盖。

上限为 512×512 格、64 个单位、8 种类型、256 个弹体/命中特效槽、16,384 条命令、单路径 4,096 格和 1,000 万步。弹体槽满时不生成炮弹、不消费随机数，记录丢弃尝试计数。当前模拟仍为单线程，后续多核结果需要与此基线逐步对照。

## 字段支持与剩余工作

本阶段在两种履带坦克及普通单发炮弹的范围内消费：Speed、ROT、Strength、Armor、Primary、TrackedUphill/Downhill、SlowdownDistance、DeaccelerationFactor、Damage、ROF、Range、Projectile、Warhead、武器 Speed、Gravity、Arcing、SubjectToCliffs/Walls/Elevation、CellSpread、PercentAtMax、Verses。Burst 目前只接受 1。

Image、美术/调色板、Track、Wall、Foundation 等沿用前阶段。INI 原文和通用规则检查器继续保留未运行字段；本阶段的有限行为不表示全部规则类型已实现。Accelerates、AccelerationFactor、MovementZone、Locomotor GUID、Crusher、桥梁双层、完整坡向、炮管位置、MinimumRange、Burst>1、弹头特殊效果、武器声音与发射动画等仍未实现。

正式入口 `reports/latest-combat.json`；验收说明见《第七阶段验收》。下一步优先用原版实场景补齐完整移动/坡向/弹道与伤害边界，再建立生产、采矿、经济和胜负流程；并行寻路应以固定命令下的状态一致为前提。AV1/HEVC 与 FFmpeg 继续保留在媒体阶段。
