# TMP 地形与真实地图预览

## 使用

运行 `D:\Program\红色警戒2\build\ra2mapviewer.exe`。默认读取原版 1.006 和中国开局验证目录，原始游戏文件只读打开。

1. 切换“原版 1.006 / 中国 MOD”，从下拉框选择地图。已知名称使用 `missions.pkt` 和 CSF 显示中文说明；无法恢复名称的包内条目显示 MIX 哈希编号。
2. 滚轮以指针位置为中心缩放，左键拖动平移。单击地形，查看格子坐标、地形编号、子块、高度、覆盖物编号和帧。
3. “适合窗口”和“原始大小”分别切换总览与原始像素。“仅显示可玩区域”采用 `LocalSize`，关闭后显示地图外围与高度留白。
4. 开关覆盖物、起点和地图对象的位置标记。红色大框标记路径点 0–7，蓝色为建筑，白色为单位，绿色为地物，金色和紫色为覆盖物。洋红色标记实际缺失的地形引用。
5. 可输入 `cliff01.tem`、`shore01.sno`、`clear01.urb` 等名称，并选择对应剧场查看 TMP 整体。单击可查询子块编号。
6. “打开地图文件”读取外部 `.map` / `.mpr`，使用当前选定的资源预设。“导出完整预览图”保存完整分辨率的 BMP。

```powershell
& 'D:\Program\红色警戒2\build\ra2mapviewer.exe' --original 'H:\开发\运行版本\原版1.006' --mod 'H:\开发\运行版本\中国开局验证'
& 'D:\Program\红色警戒2\scripts\verify-maps.ps1' -AddressSanitizer
```

原生窗口自检使用 `--self-test <已有输出目录>`，通过真实控件消息操作两套预设、三种剧场、图层、缩放、拖动和 TMP，并保存窗口截图。自检结束后关闭测试窗口。

## 已实现的数据

公共纯 C 接口位于 `include/ra2/map.h`。解析结果在构造后只读；输入保持不变。TMP 的像素和深度借用原文件，必须在释放文件前关闭 TMP；地图复制 INI、地形记录、对象与解压后的包，成功返回后可关闭原地图文件。

| 内容 | 当前行为 |
|---|---|
| TMP | 16 字节文件头、子块偏移表、52 字节子块头、菱形像素、额外矩形、深度、雷达色、高度、坡道及地形属性 |
| TMP 布局 | 零偏移子块保留为空；支持 60×30 和 48×24；验证偏移、面积和数据范围 |
| LZO1X | 独立 C 实现 v0 解码，验证字典距离、重叠复制、输入消费和精确输出长度 |
| LCW / Format80 | 立即数、相对短复制、绝对/相对长复制、填充及结束指令 |
| 地图压缩段 | 数字键排序、重复键末次生效、连续编号、严格 Base64 和分块长度检查 |
| IsoMapPack5 | 11 字节记录，保留 32 位地形值、子块、高度及冰面字段；兼容四字节零坐标结束标记 |
| 默认地形 | 未存储的格子补为零高度普通地表；65535 / -1 地形编号预览为 `clear01` |
| 覆盖物 | 解码 512×512 的 OverlayPack / OverlayDataPack，保留每个格子的类型和帧 |
| 预览包 | 解码并校验 RGB PreviewPack 的尺寸，供独立验收；主画面直接绘制 TMP |
| 对象布局 | Waypoints、Structures、Units、Infantry、Aircraft、Terrain、Smudge 的位置、标识及所属方 |
| 其他地图内容 | Basic、Lighting、触发、任务脚本、队伍和局部规则等全部保留在地图 INI 中 |

TMP 菱形每行从 4 像素递增，到中心后递减；60×30 的实际像素数为 900。额外图像使用头内偏移及透明索引零，坐标相对于所属子块定位。完整地图采用每格 30×15 的等角基向量，高度每级向上移动 15 像素；按地形格顺序绘制并保存像素到格子的查询表。

地图中存在编辑器留下的负坐标和图外路径点，保留并单独计数。原版 `TN01T2.map` 的两个节外参数由地图适配层归入 `__RA2_Map_Preamble`，行号恢复为源文件行号，不放宽通用 INI 解析器。

## 挂载与范围

复用前阶段的明确优先级：基础资源 10–16，通用等角地形 20，温带/雪地/城市等角包 21–23，语言资源 30/40，原版散文件 50，中国附加包 100，中国散文件 200。

地图阶段直接读取选定目录中的 `MULTI.MIX`、`MAPS01.MIX`、`MAPS02.MIX`。地形包也读取该预设目录的 `ra2.mix`，包括 `isogen.mix`、`isotemp.mix`、`isosnow.mix`、`isourb.mix`、`temperat.mix`、`snow.mix`、`urban.mix`。完整地形枚举覆盖已知名称外的变体；不识别为 TMP 的成员另行计数，独立检查确认它们属于 SHP。

地形编号使用 `temperat.ini`、`snow.ini`、`urban.ini` 中依序累计的 `TilesInSet`，对应 `FileName + 两位编号 + 扩展名`。当前只支持原版 1.006 的三个剧场，普通地表采用基础变体；不模拟随机地表变体选择。

当前中国目录的 `ra2.mix`、语言包和三个地图包与基线逐字节摘要一致。地图由中国目录实际读取，规则和 CSF 使用中国覆盖，不能把继承地图表述为中国新增地图。

## 当前边界

这是实际地形和地图布局预览。建筑、单位、树木和覆盖物当前使用位置标记，尚未在地图中组合 SHP / VXL 图像、建筑地基和动画。原有 SHP / VXL 查看器仍可分别查看这些美术资源。

TMP 深度数据已解析，但地图绘制使用有序绘制，尚未实现原版逐像素深度规则、阴影、光照、雾、桥上单位或水面动画；不承诺与原版画面逐像素相同。地图局部规则保留供后续运行层处理，尚不执行触发、任务或战役流程。没有模拟、寻路、AI、存档、联机或多核调度。

单幅地图最多 6,710 万像素，超过限制会返回错误；失败加载保留已有预览。查看器按需缓存地形，两套资源均关闭后释放映射。

`ra2mapcheck <原版目录> [中国目录]` 输出完整 JSON，包含每张地图的实际来源、摘要、全部缺失格、样本坐标，以及全部 TMP 和地形 INI 空置名称。格式错误返回 1；默认保留引用警告并返回 0，增加 `--strict` 时缺失引用返回 2。`--dump <资源名>` 输出只读原始字节供独立验收；`--samples <已有目录>` 另存三张代表地图的完整 BMP。
