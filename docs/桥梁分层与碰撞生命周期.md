本轮在 `D:\Program\红色警戒2` 延续纯 C17 开发，以原版 1.006 的现有资源和隔离指令执行作为参考。旧项目、游戏输入和中国设计文档不由本轮修改。中国阵营仍是禁用的 `future.china` 接口。

## 桥面与桥下

地图节点扩展为两层：地面节点 `cell`，桥面节点 `width * height + cell`。两层分别拥有地表属性、占格、预占格和寻路状态；坐标投影不把层号误算成地图 Y。寻路、连续弯道采样、停靠、散开、路径点、攻击高度、选择与回放均识别层号。轨迹跨桥口时按实际采样位置确定楼层，避免单位先消失在桥图下面、到达格中心后才突然出现。

高桥面比其基底高四层，每层为 104 lepton。普通坦克从同高岸边沿桥长进入和离开，不能从桥下垂直跳上桥面，也不能从侧面穿过栏杆。三格宽桥面与桥下独立占格，停靠和摧毁会清理对应层的预占格。原版 `4c8730` 的桥标志、高度差、初始化层号和桥口转换单独实现为 `battle_bridge_test`；原有地面坡向对照继续保留。

实际地图识别 `BRIDGE1/2`、`BRIDGEB1/2`。本轮开放已确认完整的帧 0、9，其他高桥帧保留桥层与图像，但阻断通行并计入 `pending_bridges`。低桥 `LOBRDG/LOBRDB` 的完整直段 01–04、10–13 和岸边段 19–26 作为地面道路处理；损毁段、未确认边饰和铁路桥仍明确阻断。不会把低桥都抬高四层。

高桥显示读取三个剧场的原始 `bridge`、`bridgb` SHP 与 ISO 调色板；地面单位、桥梁图像、桥上单位分层合成，桥面菱形提供独立鼠标命中区。保持原有左键选择/下令、右键取消和原版快捷键。桥图遮挡目前是图层顺序，尚不是原版逐像素深度与栏杆遮挡的完整复刻。

低桥图块命名和完整/损毁分组参考 [OpenRA RA2 的资源序列表](https://github.com/OpenRA/ra2/blob/master/mods/ra2/sequences/bridges.yaml)，并核对本地规则和实际地图；这些名称参考不等于原版全部损毁拓扑已验证。

## 坡面底盘和炮口

`battle_matrix.c` 使用原版数学初始化得到的 21 个坡面基矩阵，按原版 32 向车身旋转合成 3×4 矩阵。矩阵乘加、float 存回和最终整数截断复用整数实现的 RZ 数值路径，不依赖宿主浮点控制字。浮点正负零在参考比较中按同一个数值处理。

显示与炮口使用同一坡面和车身方向。坡面来自单位实际坐标所在格，不能一直沿用上一逻辑格。显示依次应用 HVA、部件转向、底盘矩阵和相机投影，法线也随底盘变换。坡面图像按单位缓存，避免为每个坡面预生成完整方向组合。

炮口按原版 `6c1830` 的顺序先平移 `TurretOffset`、再旋转相对炮塔方向、再应用 `PrimaryFireFLH`，支持非零炮塔偏移。以原版 `53d0d0`、`5909a0` 和完整炮口路径对照全部坡面与车身/炮塔组合。这里只完成静态坡面底盘；受击摇摆、履带悬挂和完整 DriveLocomotor 动态姿态仍需场景采样。

## 常规炮弹生命周期

当前两种坦克的普通无制导 Cannon 保留重力先更新、位置逐步截断的数值路径，并补齐以下状态：

1. `active=0`：空槽；发射时建立弹体、炮口、速度、目标和引信状态。
2. `active=1`：飞行；检查桥面上穿/下穿、地面、墙与悬崖、近目标格、邻近敌方对象、出界和终止边界。
3. `active=2`：已结算命中，展示爆炸；伤害只结算一次，不能再次推进或重复摧毁。
4. `active=3`：退场；保留退场步及原因供逐步校验，下一步清空槽位。

下落穿过桥面时落点夹到桥面，上升撞桥底时夹到桥面以下 20 lepton。等号边界分别按原版指令检查。墙体使用近地 150 lepton 条件，悬崖扫格使用实际地表高度，删除旧版人为添加的墙高 64 和岩石高 104。

触地后不能立即结束：原版还会继续判断目标格并在满足距离条件时修正到仍有效的目标坐标。本轮恢复这一顺序。因此四格重甲夹具的首次伤害现在为 65，轻甲为 48，400 生命目标需七发；上一阶段 39/29 的结果属于旧的近似落点，不再是本轮金值。只有仍有效且满足原版距离门限的目标才会进行坐标修正；目标移动较远、消失或被摧毁后，按当前落点结算。

新增 `Arm`、`Proximity`、`Ranged` 的基础引信状态和最近距离；数值门限对照原版 `4ceee0`。普通 Cannon 的默认值不启用近炸。出界和防御性超时进入有原因的退场，不结算无依据的伤害。当前爆炸显示保留 13 个模拟步，这仍是最小战场的显示约定。

这里的“生命周期完整”指当前普通坦克弹体从发射、碰撞、单次结算到释放槽位的闭环。建筑几何、多节桥损毁/修复、坠桥、反弹、穿透、制导、集束、空爆和特殊弹头不在本轮完成范围；墙/悬崖扫格也未宣称等同于原版所有几何分支。发射者死亡后继续推进已有弹体已作确定性回归，但尚未取得原版整局中所有所有者失效分支的证据。

## 索敌候选

威胁评分之前统一过滤死亡、离场/下沉、不可选中、免疫、不可见、未侦测隐形、当前普通坦克不能攻击的水下或空中状态，以及同一桥格的不同层。读取弹道 `AA/AG`，过滤无效护甲、零伤害和零 Verses；主动索敌与受击报复分别保留 2% 和 1% 的边界。目标中途失效后重新选取候选，原来的移动攻击、警戒和巡逻任务不因此丢失。

普通候选的生命、离场、可见性、隐形侦测和低于地表门限，与原版 `6c5570` 的前置分支隔离对照。AA/AG、Verses、免疫和跨桥层组合另有 C 回归。隐藏与侦测掩码是模拟接口；本轮没有把它们冒充为已完成的战争迷雾、隐形装置或空军系统。建筑、维修/治疗、伪装、同盟外交和特殊武器的全部候选类别仍待相应对象系统接入。
