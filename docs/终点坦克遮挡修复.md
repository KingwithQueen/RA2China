# 终点坦克模型被桥梁覆盖的修复

这是显示错误。坦克过桥到岸后，模拟层号正确地切回地面，但旧绘制顺序会在所有地面单位之后覆盖整张桥图，导致接岸处的车身被截掉。

新增的完整模型回归在修改前实际失败：`MP06T2.map` 的终点坦克应显示 1,860 个像素，实际只显示 1,360 个，500 个被桥图覆盖。修改后的同一场景显示 1,860 / 1,860 个像素，桥下显示探针仍被遮挡。

## 实现

- `battle_scene.c` 为每个高桥图像像素保存所属桥段的高度；桥梁损坏、摧毁、修复和切换地图时随图像一起更新、释放。
- 固定战场相机的体素深度与屏幕纵坐标可以还原像素高度。桥图覆盖单位前比较两者高度，已经到岸的车体继续可见，真正位于桥下的像素仍被遮住。选择命中图与画面同步。
- `battle_viewer.c` 的窗口回归逐像素比较完整模型的颜色与命中标识，补测停稳后的目的地、反向返回、两种坦克、八个朝向、三档缩放和桥下遮挡。桥梁生命周期测试另增加修复后到达终点的截图与完整性检查。
- `render_test.c` 使用高度范围已知的合成体素独立验证高度逆变换，不依赖桥口测试的实现判断。

本次仍使用纯 C17 和中文注释，十三份模拟核心源文件保持原样。固定模拟为 15 步/秒，版本 7，回放为 `RA2RPL9`。中国阵营仍只保留接口。原版栏杆自身的精细高度与原版整局逐像素对照仍属于后续显示校准。
